## Overview

This repository contains the practical deliverables for the 1-Month AI Internship at Codec Technologies. It includes end-to-end Machine Learning and Deep Learning implementations focusing on Computer Vision and Natural Language Processing.

---

## Project Highlights

### 1. Handwritten Digit Recognizer (MNIST)
- **Objective:** Design and train a Deep Learning model to accurately identify handwritten numerical digits (0–9).
- **Architecture:** Convolutional Neural Network (CNN) built using TensorFlow and Keras.
- **Methodology:** Standardized image pixel values to $[0, 1]$ range and applied 2D Convolutional and Max Pooling layers.
- **Performance:** Reached **98.68% test accuracy**.

### 2. Spam Email Classifier
- **Objective:** Train a Natural Language Processing (NLP) model to classify text messages/emails as Spam or Ham.
- **Methodology:** Converted raw text into TF-IDF numerical vectors and trained a Naive Bayes classifier.
- **Performance:** Achieved high precision and accuracy on the SMS Spam Collection dataset.
